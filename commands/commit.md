escription: Analisa alterações e cria commits Git organizados e seguros
agent: git-commit
subtask: true

---

Analise todas as alterações atuais deste repositório e execute o fluxo completo de criação de commits.

Separe as alterações em commits lógicos somente quando isso realmente melhorar o histórico.

Antes de criar qualquer commit:

- examine o status e os diffs;
- verifique arquivos sensíveis;
- confira exatamente o que será preparado;
- apresente brevemente o plano de commits.

Crie os commits seguindo Conventional Commits, em português do Brasil, com título objetivo e corpo explicativo quando necessário.

Após criar os commits, verifique se existem commits locais pendentes de envio.

Mostre a branch, o repositório remoto, os commits pendentes e o comando de push.

Solicite aprovação antes de executar o push.

Nunca utilize push forçado e nunca execute push sem aprovação explícita.
