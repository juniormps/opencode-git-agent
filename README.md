# 🚀 OpenCode Professional Git Agent

Um agente para **OpenCode** que automatiza o fluxo de Git com segurança, organização e boas práticas.

Projetado para desenvolvedores que desejam agilizar o processo de commits sem abrir mão do controle sobre operações críticas.

# 💸 Baixo custo

Este projeto foi concebido com foco em **baixo custo**.

Ele utiliza o **OpenCode**, uma ferramenta open source, e pode ser integrado a modelos de IA acessíveis, permitindo automatizar o fluxo de Git sem depender de soluções proprietárias caras.

O objetivo é oferecer uma experiência profissional com excelente custo-benefício para estudantes, desenvolvedores independentes e equipes.

# 📦 Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/opencode-git-agent.git

cd opencode-git-agent
```

Copie o agente:

```bash
cp agents/git-commit.md ~/.config/opencode/agents/
```

Copie o comando:

```bash
cp commands/commit.md ~/.config/opencode/commands/
```

Pronto!

---

# 🚀 Utilização

Entre em qualquer projeto Git:

```bash
cd caminho/do/projeto
```

Abra o OpenCode:

```bash
opencode
```

Execute:

```text
/commit
```

O agente irá:

- analisar todas as alterações;
- identificar arquivos sensíveis;
- organizar commits logicamente;
- gerar mensagens seguindo Conventional Commits;
- solicitar aprovação antes do commit;
- solicitar aprovação antes do push.
