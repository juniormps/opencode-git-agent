# OpenCode Professional Git Agent

Agente para OpenCode que automatiza o fluxo de Git com segurança.

## Recursos

- análise inteligente das alterações
- Conventional Commits
- separação automática em commits lógicos
- detecção de arquivos sensíveis
- proteção contra push forçado
- confirmação antes de commit
- confirmação antes de push
- suporte a qualquer IDE

## Instalação

Clone o repositório:

git clone ...

Copie os arquivos:

cp agents/git-commit.md ~/.config/opencode/agents/

cp commands/commit.md ~/.config/opencode/commands/

Pronto.

## Uso

Dentro de qualquer projeto:

opencode

Depois:

/commit
